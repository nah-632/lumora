# LUMORA

A bilingual (Arabic/English) AI teaching assistant for teachers in the Kingdom of Bahrain.
Arabic is the default and RTL is the primary layout; English is a full LTR version.

The authority for this repository is [LUMORA-CONSTITUTION.md](LUMORA-CONSTITUTION.md).
Read it, and [AGENTS.md](AGENTS.md), before changing anything.

## UI

All new interface work must follow [`lumora-design/SKILL.md`](lumora-design/SKILL.md) and
[`lumora-design/DESIGN.md`](lumora-design/DESIGN.md) — the brand palette, Arabic-first RTL
typography, and the type scale are fixed there. No gradients beyond the hero image and the
logo, and no invented testimonials, statistics or prices.
